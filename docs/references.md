# Design references

These references support the database techniques used in MarketHubDB. The implementation, diagrams and fictional dataset are project artifacts, not copies of the source material.

1. Microsoft Learn. [Primary and foreign key constraints](https://learn.microsoft.com/en-us/sql/relational-databases/tables/primary-and-foreign-key-constraints?view=sql-server-ver17). Key uniqueness and parent–child referential integrity.
2. Microsoft Support. [Database design basics](https://support.microsoft.com/en-us/access/database-design-basics). Separating entities and removing redundant facts through normalization.
3. Microsoft Learn. [CREATE TABLE (Transact-SQL)](https://learn.microsoft.com/en-us/sql/t-sql/statements/create-table-transact-sql?view=sql-server-ver17). SQL Server types, nullability, keys and check constraints.
4. Microsoft Learn. [SET XACT_ABORT](https://learn.microsoft.com/en-us/sql/t-sql/statements/set-xact-abort-transact-sql?view=sql-server-ver16). Runtime-error handling for transactional operations.

## Project origin

MarketHubDB is an independent portfolio rebuild of an academic retail-database scenario. The repository contains newly authored implementation and documentation with fictional data. It does not reproduce private course files, signatures, grades or instructor feedback.
